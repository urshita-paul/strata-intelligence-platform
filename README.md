# STRATA Intelligence Platform

Build a professional environmental intelligence web application named STRATA.

STRATA is an AI-powered pollution event intelligence and early warning platform.

The application is designed for environmental analysts and pollution-control authorities.

DESIGN:

Professional geospatial intelligence dashboard.

Dark navy, charcoal, muted teal and clean white colour palette.

Modern typography.

Clean data visualisations.

High information density without clutter.

Desktop-first responsive layout.

CREATE THE FOLLOWING PAGES:

Overview Dashboard

Pollution Event Map

Event Intelligence

AI-generated Reports

Early Warning Centre

Historical Analytics

Settings

GLOBAL NAVIGATION:

Fixed sidebar.

STRATA logo and branding.

Active page highlighting.

Search and notification controls.

Consistent navigation across every page.

IMPORTANT:
Use realistic demonstration data initially.
Clearly label all simulated data.
Create reusable components.
Do not create disconnected static mockup pages. Make the navigation and interactions functional.

For now, focus on the frontend and application structure. Do not implement the machine learning model yet.
